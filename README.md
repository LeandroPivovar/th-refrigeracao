# TH Refrigeração - site institucional

Site one-page da **TH Refrigeração**, oficina especializada em ar-condicionado automotivo em Volta Redonda - RJ.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, depoimentos, mapa, FAQ)
styles.css   # estilos (tema escuro com azul-gelo)
script.js    # menu mobile, header ao rolar, animações, carrossel, FAQ
assets/      # favicon e fotos
```

Sem build: HTML, CSS e JS puros.
